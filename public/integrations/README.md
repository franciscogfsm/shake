# Integration artwork

`stellar.svg` and `openzeppelin.svg` are brand marks sourced from [Simple Icons](https://github.com/simple-icons/simple-icons), distributed under [CC0-1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md), and rendered in SHAKE's glacier-blue palette. Brand names and marks belong to their respective owners; their appearance identifies technologies used by SHAKE, not an endorsement.

`passkey.svg`, `token.svg`, `anchor.svg`, and `proof.svg` are custom capability icons for passkey authorization, test assets, SEP-24 withdrawals, and receipts. They are not third-party logos.

All artwork is self-hosted. The README integration strip embeds the same artwork in `docs/assets/integrations.svg`.
